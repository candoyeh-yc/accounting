# 壹、113 年

## 一、測驗逐題逐選項

### Q1（官方 A｜考生答 C ❌）何種股東會決議得適用 §175 假決議？
- (A) ✅ 董事報酬之決定＝普通決議（§196），假決議只救普通決議定足數不足，故適用。
- (B) ✗ 監察人選任採累積投票制（§227準用§198），屬「選舉」非「表決」，不適用假決議。
- (C) ✗（← 你選這個）盈餘轉增資配股＝**特別決議**（§240Ⅰ，2/3出席），特別決議不能假決議。你被「發行新股」字面勾走，忘了它是特別決議。
- (D) ✗ 與他人經常共同經營契約＝特別決議（§185Ⅰ③）。
> 💡假決議只適用「普通決議」事項；看到特別決議（§185/§209/§240/§277）一律排除。

### Q2（官方 D｜考生答 A ❌）重整聲請權人？
- (A) ✗（← 你選）「繼續**1年**以上持股10%股東」→ 錯在年限，應為**繼續6個月**（§282Ⅰ①）。
- (B) ✗ 「相當於公司**負債總額**10%債權人」→ 錯，應為「已發行股份總數**金額**10%以上」之公司債權人（§282Ⅰ②）。
- (C) ✗ 「同業公會」→ 錯，應為**工會**（§282Ⅰ③）。
- (D) ✅ 公司**2/3以上受僱員工**（§282Ⅰ④）。
> 💡重整聲請＝公司自己＋股東(6月+10%)＋債權人(金額10%)＋工會＋2/3員工；限**公開發行**公司。

### Q3（官方 D｜考生答 A ❌）非公開發行公司，何者錯誤？
- (A) ✗（← 你選，但這是正確敘述）得經股東會特別決議將票面股全數轉無票面股（§156-1）→ 對。
- (B) ✗ 得依章程發行對特定事項具否決權特別股（黃金股）→ 非公開發行可發，對。
- (C) ✗ 複數表決權特別股股東，選監察人時表決權與普通股同（§157）→ 對。
- (D) ✅（錯誤敘述，選它）「不得發行當選一定名額董事之特別股」→ 錯，非公開發行**得**發（§157Ⅰ⑤）。
> 💡「何者錯誤」題要找假敘述；此題陷阱是(A)(C)兩個真敘述看起來冷門易被誤選。

### Q4（官方 C｜考生答 C ✅）有限公司董事甲轉讓出資？
- (A) ✗ 自由轉讓 → 有限公司出資轉讓有限制。
- (B) ✗ 其他股東表決權過半數同意 → 那是「非董事股東」門檻（§111Ⅰ）。
- (C) ✅ 其他股東表決權**2/3以上**同意（§111Ⅲ，董事門檻較高）。
- (D) ✗ 僅得轉讓予其他股東 → 可轉讓予他人，只是要2/3同意。
> 💡有限公司：一般股東轉讓＝過半同意；**董事**轉讓＝2/3同意。

### Q5（官方 D｜考生答 A ❌）企業社會責任，何者錯誤？
- (A) ✗（← 你選，但為正確敘述）公司＝以營利為目的之社團法人（§1Ⅰ）→ 對。
- (B) ✗ 得採增進公共利益之行為（§1Ⅱ）→ 對。
- (C) ✗ 公司得為（合理）贈與 → 對。
- (D) ✅（錯誤敘述）「兼營利與公益尚不可採公司組織」→ 錯，§1Ⅱ已容許、社會企業可用公司型態。
> 💡§1Ⅱ（2018修）：公司得採增進公共利益行為以善盡社會責任——這是修法新增，常考。

### Q6（官方 D｜考生答 C ❌）A公司應向資訊平臺申報何人？
> 結構：B持A 9%、C持A 8%；B與C全由D持有；甲持D 51%。
- (A) ✗ B公司直接持9% → 未達10%（§22-1申報門檻）。
- (B) ✗ D公司 → 間接持股（持B、C），非A之直接股東，§22-1**不穿透**。
- (C) ✗（← 你選）自然人甲（持D 51%）→ 更間接，非A股東。你被誘去算「最終受益人」，但公司法§22-1沒有穿透申報。
- (D) ✅ A公司經理人乙 → §22-1明文應申報「董事、監察人、**經理人**及直接持股>10%股東」。
> 💡§22-1申報＝董監經理人＋**直接**持股>10%股東；別跟洗錢防制法的實質受益人穿透混淆。

### Q7（官方 C｜考生答 C ✅）發行新股，何者正確？
- (A) ✗ 「新股認購權不得與原股份分離獨立轉讓」→ 錯，**得**分離獨立轉讓（§267Ⅳ）。
- (B) ✗ 發特別股時員工無優先認購 → 錯，員工承購權不分普通/特別股。
- (C) ✅ 應保留10-15%予員工，經目的事業主管機關專案核定者不在此限（§267Ⅰ）。
- (D) ✗ 特別股股東無優先認購權 → 錯，原股東（含特別股）有（§267Ⅲ）。

### Q8（官方 D｜考生答 C ❌）誰得為公司登記代理人？
- (A) ✗ 律師、代書 → 代書（地政士）不可。
- (B) ✗ 代書、記帳士 → 都不可。
- (C) ✗（← 你選）記帳士、會計師 → 記帳士只能代理稅務申報，不得代理公司登記。
- (D) ✅ 律師、會計師。
> 💡公司登記代理＝律師 or 會計師；記帳士/地政士不行。

### Q9（官方 C｜考生答 C ✅）股東會臨時動議改選總經理，效力？
- (A) ✗ 有效。
- (B) ✗ 得撤銷 → 那是「程序」瑕疵（§189）。
- (C) ✅ 無效：經理人委任解任是**董事會**專屬職權（§29Ⅰ），股東會決議此事＝內容違法 → §191無效。
- (D) ✗ 須原總經理承認。
> 💡程序瑕疵→得撤銷(§189)；內容違法→無效(§191)。經理人任免＝董事會職權。

### Q10（官方 B｜考生答 空白 ❌）股票發行，何者正確？
- (A) ✗ 非公開發行公司實收5億以上應發行股票 → 錯（舊制已廢，非公開發行無強制發行義務）。
- (B) ✅ 公開發行股票公司有發行股票之義務（§161-1）。
- (C) ✗ 「6個月內」發行 → 錯，應為設立/變更登記後**3個月**內。
- (D) ✗ 無發行義務公司發股須主管機關核准 → 錯，無需核准。
> 💡這題你空白——考場寧可猜也別留白，四選一期望值都是正的。

### Q11（官方 C｜考生答 C ✅）董事競業，何者符合規定？
- (A) ✗ 僅需許可、無須說明重要內容 → 錯，須向股東會說明重要內容（§209Ⅰ）。
- (B) ✗ 許可用普通決議 → 錯，許可須**特別決議**。
- (C) ✅ 未經同意兼職→股東會得以普通決議（½出席、過半同意）將所得視為公司所得（歸入權§209Ⅴ）。
- (D) ✗ 歸入權限於「決議前2年」→ 錯，是「所得產生後逾**1年**不行使而消滅」。
> 💡許可＝特別決議；行使歸入權＝普通決議；歸入權時效**1年**。

### Q12（官方 C｜考生答 A ❌）公司外文名稱，何者正確？
- (A) ✗（← 你選）英文名稱登記前應預查 → 錯，外文名稱**不需預查**（只有中文名稱要，§18Ⅴ）。
- (B) ✗ 完成登記前不得對外使用 → 錯。
- (C) ✅ 欲登記英文名稱應於**章程中記載**。
- (D) ✗ 與公益團體同名經濟部得逕予廢止 → 錯。
> 💡外文名稱：不需預查、須章程記載（2018新增§18）。

### Q13（官方 A｜考生答 B ❌）集中市場買賣契約成立於誰之間？
- (A) ✅ A與C之間（買方經紀商與賣方經紀商）：經紀商是**行紀**，以自己名義為客戶計算買賣。

- (C) ✗ 甲與C。
- (D) ✗ 乙與A。
> 💡行紀：客戶↔經紀商是委託關係；市場成交契約成立於**兩經紀商間**。

### Q14（官方 C｜考生答 C ✅）私募，何者錯誤？

## 二、申論詳解＋加強點（113）

### 申論一：法人董事改派 ＋ 表見代理（20分，你約 19，掌握極佳）
**①丁是否合法就任董事長？**
- 法條：§27Ⅲ 法人股東得隨時改派代表人補足原任期；§208Ⅰ 董事長由**董事會**選舉產生。
- 正解：B公司改派丁為代表人，丁承繼**董事**地位合法；但「董事長」須經**董事會依§208重新選舉**，法人股東無權逕行「指定」。故**丁就任董事長不合法**（辦妥變更登記不能補正選任瑕疵）。
- 你的作答：「不合法，重新指派後不當然為董事長，應由董事會重新選任」→ 核心完全正確。
**②A公司可否拒付1800萬？**
- 法條：§208Ⅲ 董事長對外代表公司；§57、§58 代表權限制不得對抗善意第三人；民§169 表見代理。
- 正解：A已將丁登記為董事長、形成外觀，C善意不知瑕疵 → A**不得**以內部選任瑕疵對抗善意之C，契約有效，**應付1800萬**；損失向丁（無權代表人，民§110）求償。
- 你的作答：完全命中表見代理、應履約、向丁求償。
**加強**：兩小題你都答對，只差引條號（§27Ⅲ、§208、§57/§58、民§169）。考場補上條號可再穩拿滿分。

### 申論二：盈餘轉增資 ＋ 現金增資（20分，你約 16.5）
**①盈餘轉增資發行新股應否申報？** 正解：證§22 有價證券之發行須向金管會**申報生效**；盈餘轉增資＝發行新股 → 應申報。（你答對）
**②現金增資3億是否合法？（本題主考點）** 三層都要寫到：
- 員工保留12%：§267Ⅰ 應保留10-15% → 12%在範圍內，合法。
- **提撥20%對外公開發行：證§28-1Ⅱ** 上市公司現金發行新股應提撥10%對外公開發行、不受§267Ⅲ原股東儘先分認限制，經股東會決議得提高比率 → 提撥20%合法。**（你漏了這層依據）**
- 餘額由原股東按持股比例分認：§267Ⅲ，合法。
**③現金增資應否申報？** 正解：證§22 應申報。（你答對）
**加強**：①③都對，②漏掉證§28-1「提撥對外公開發行、排除原股東儘先分認、股東會得提高」——這是整題的得分核心，補上這一段即滿分。

### 申論三：決算報表（商業會計法，10分，你約 6）
**①至遲多久、由誰提請承認？不編罰則？承認是否解責？**

- 你的作答：「是，甲雖非名義董事，依§8實質控制董事會，民刑行政責任與董事同」→ 完全正確。
**加強**：兩小題近滿分，僅補條號（§214、§8Ⅲ、§23）與乙的門檻要件即滿分。

### 申論二：公開說明書不實 §32（20分，你約 10，深度不足★最需補）
> 甲要求乙於公說書虛增應收帳款1億；丙（會計師）因A信用良好即簽證；丁承銷；戊善意以25元認購。
**責任主體與免責（§32）**——五個人逐一寫：
- **A公司（發行人）**：§32Ⅰ①，**無過失責任、不得免責** → 應對戊賠償。
- **甲（負責人）**：§32Ⅰ①，得舉證「已盡相當注意」免責；但甲**主動要求虛增（明知不實）**→ 無正當理由確信無虛偽 → **不能免責**。
- **乙（簽章職員）**：§32Ⅰ②，受指示執行虛增 → 難謂已盡相當注意 → 應負責。
- **丙（專家會計師）**：§32Ⅰ④，須證明「**已經合理調查**」（門檻高於相當注意）；丙「因信用良好即簽證」＝未執行合理查核 → **不能免責**。
- **丁（承銷商）**：§32Ⅰ③，就非專家簽證部分得證明已盡相當注意免責；能否免責視其查核。
- **賠償**：對善意之戊負**連帶**賠償，範圍＝認購價25元與真實價值/現價之差額。
**你的作答**：「§32，A無過失不得免責；甲乙丙丁應負責但可舉證免責」→ 架構對，但20分題只寫兩行。
**加強（逐項採分，你10/20）**：拿到§32＋A無過失（4分）；丟分在③主體沒分類④免責標準沒分兩級（**專家＝合理調查 vs 其他＝相當注意**）⑤**沒涵攝個案**（甲明知、丙未查核→其實免不了責，你卻寫「可舉證免責」）⑥漏賠償範圍。**心法：題目寫某人「明知/主動要求/未查核即簽證」＝暗示其免責失敗，要順勢寫「不能證明已盡相當注意/合理調查，應負責」。**
