## 一、公司法（測驗主力 12 題＋申論 1 題）

| 條 | 規則 | 關鍵數字/要點 |
|---|---|---|
| §15 | 資金貸與限制 | 僅「業務往來」或「短期融通」；融通上限＝貸與企業**淨值 40%** ⚠ |
| §16 | 非依法不得為保證 | 無授權之保證→負責人自負責任 |
| §23 | 負責人**忠實義務**＋善良管理人注意 | 違反致損害負賠償；違反競業歸入權 |
| §167-1 | 庫藏股買回 | 上限**已發行股份 5%**、金額≤保留盈餘＋已實現資本公積；**3 年內**轉讓員工，逾期視為未發行 |
| §192 / 證§26-3 | 董事人數 | 一般 **≥3**；公開發行 **≥5**；閉鎖/一人公司得 1 人 |
| §203、§208 | 董事會召集 | 董事長召集；董事長請假由副/常董代理；少數董事請求後一定期間不召集得自行召集 |
| §206 準用 §178 | 董事利益衝突 | 說明利害關係要旨、**迴避表決**；違反→決議得撤銷 |
| §213／§223 | 公司與董事間 | 訴訟由**監察人**代表；買賣/借貸/其他由**監察人**代表公司 |
| §157 | 特別股 | 複數表決權、**否決權特別股（僅非公開發行得發）**、當選一定名額董事、無票面金額股 |
| §267 | 發行新股 | 員工保留 **10–15%**；原股東按持股比例**儘先分認**；計算題常考 |
| §111 | 有限公司出資轉讓 | **董事需其他股東表決權 2/3**、非董事股東需**過半**同意 |
| §369-2~ | 關係企業 | 控制從屬（持股過半 或 控制人事財務業務）；不合營業常規未補償→賠償；實質董事責任 |
| §8 | 負責人範圍 | 當然（董事）＋職務（經理人/監察人等）＋**實質**負責人（實質董事） |

## 二、證券交易法（高頻數字題＋申論 1 題）

| 條 | 規則 | 關鍵數字/要點 |
|---|---|---|
| §22-2 | 董監經理人持股轉讓 | 三方式：申報日起 **3 日後**集中市場／向特定人／3 日內私下；每日≤一定張數免申報 |
| §25 | 持股變動申報 | 每月 **5 日前**申報上月變動；質押亦申報 |
| §32 | 公開說明書不實民事責任 | 求償：**發行人（公司無過失）**、負責人、簽章職員、承銷商、專家（會計師/律師**得舉證免責**）；保護善意投資人 |
| §36 | 財報申報 | 年報**3 個月**內、季報**45 日**內、月營收次月 **10 日**前；重編門檻（金額＋占總資產比例）|
| §43-1 | 強制公開收購 | 取得公發股份達 **20%**（50 日內）應採公開收購 ⚠ |
| §43-6、43-8 | 私募 | 股東會**特別決議**；應募人 **35 人**（金融機構不計入）；**15 日**內報備查；交付**滿 3 年**始得轉售 |
| §155 | 操縱市場 | 沖洗買賣、相對委託、連續交易、違約不交割 |
| §157 | 短線交易歸入權 | 取得後 **6 月**內買賣差價歸入；董監經理人＋**>10%**股東；股東請求董事會，**30 日**不行使得自行 |
| §157-1 | 內線交易 | 消息明確後、公開前或公開後 **18 小時**內不得買賣；公司債亦適用；賠償＝公開後 **10 營業日**收盤均價差額，重大得增 **3 倍** |
| §171 | 特別背信/侵占 | 損害 **500 萬**以上加重；犯罪所得 **1 億**以上再加重；不合營業常規交易 ⚠ |

## 三、商業會計法（申論每年必出 1 題＋測驗約 4 題）★★★

| 條 | 規則 | 關鍵數字/要點 |
|---|---|---|
| §5 | 主辦會計任免同意門檻 | 股份公司**董事會過半**；有限公司**全體股東過半**；無限/兩合**全體無限責任股東過半** |
| §9 | 現金收付 | 支出達一定金額應透過金融機構（匯票/本票/支票/劃撥等）⚠ |
| §14~§17 | 會計憑證 | 原始憑證 vs 記帳憑證（收入/支出/轉帳傳票）；轉帳傳票仍有記帳憑證效力；簡易事務得不編記帳憑證 |
| 決算報表簽章 | ⭐113、114 連兩年申論 | 決算報表由**負責人＋經理人＋主辦＋經辦會計人員**簽章；至遲於會計年度終了一定期間內提請承認；**承認不解除責任** |
| §71 | 不實憑證/帳簿刑責 | 主辦/經辦會計人員等，**5 年以下**有期徒刑、拘役或科/併科 **60 萬以下**罰金 ⚠；事前拒絕或更正得減免 |
