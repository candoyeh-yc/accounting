# 審計學 深掘⑦｜內部控制（265/315）與專家工作（620）★★★

> 內部控制是測驗年年出、專家工作五年每年出一題。本篇補齊兩者完整要件。

---

## 一、內部控制五大組成要素（315）

| 要素 | 內涵 | 層級影響 |
|---|---|---|
| **控制環境** | 治理與管理對誠信、價值觀、勝任能力之態度與行動 | 間接，影響**整體財報**層級 |
| **受查者風險評估流程** | 受查者辨認、評估、因應營運風險之流程 | 間接，整體財報層級 |
| **監督內部控制制度之流程** | 受查者評估控制是否持續有效（含內稽）| 間接，整體財報層級 |
| **資訊系統與溝通** | 與財報攸關之資訊產生、記錄、處理、報導及溝通 | 較直接，影響**個別聲明**層級 |
| **控制作業** | 確保管理階層指令執行之政策與程序（核准、覆核、分工、實體控制、資訊處理控制）| 直接，影響**個別聲明**層級 |

**口訣**：前三間接（整體財報）、後二直接（個別聲明）。

### 控制了解之程度
- 查核人員須了解與查核**攸關**之控制，並評估其**設計**是否適當、是否**付諸實行**。
- 「付諸實行」≠「執行有效」——了解階段確認控制存在並運作，**有效性須靠控制測試**。

---

## 二、IT 控制（資訊科技）★★
- **一般控制（ITGC）**：對 IT 環境整體之控制——存取權限、程式變更、系統開發、資料中心營運。支撐應用控制有效運作。
- **應用控制（資訊處理控制）**：嵌於個別交易流程之自動化控制——輸入檢核、運算邏輯、勾稽。
- 高度自動化、無實體軌跡之流程（如手遊收入）→ **僅證實程序無法取得足夠證據**，必須測試 IT 控制（呼應 112-申1、06 篇）。
- 自動化控制特性：一致性高，**確認其付諸實行後**，配合 ITGC 有效，可推論其持續有效（人工控制則須逐次測）。

---

## 三、內部控制缺失之溝通（265）★★★
| 缺失程度 | 溝通對象 | 方式 |
|---|---|---|
| **顯著缺失** | 治理單位（及管理階層）| **應以書面**、及時 |
| 一般缺失 | 管理階層 | 得口頭 |

- 「顯著缺失」＝足以引起治理單位注意之一項或數項控制缺失組合。
- 顯著與否取決於**潛在不實表達之金額大小與發生可能性**（不以是否實際發生為準）。
- 查核人員**不得**出具「未發現其他內部控制缺失」之保證；但管理階層/治理單位**要求**出具「未辨認出顯著缺失」之書面溝通者，**得**出具。
- 查核人員對內部控制有效性**不表示意見**（除非另受託專案）。

## 四、查核人員專家 vs 管理階層專家（620）★★★

| | 查核人員專家 | 管理階層專家 |
|---|---|---|
| 受誰委任 | 查核人員聘僱/委任 | 管理階層聘僱/委任 |
| 角色 | 協助查核人員取得查核證據 | 協助受查者編製財報 |
| 查核人員之作為 | 評估其適任、客觀；了解其領域；評估工作適切 | 評估其能力、客觀性、工作適切性；其工作視為受查者資訊 |
| 領域 | 會計或審計**以外**之專門知識（估價、精算、工程…）| 同 |

### 共同要點
- 採用專家工作**不減輕**查核人員之查核責任（責任仍在會計師）。
- 評估專家須考量：**專業能力、適任能力、客觀性**，及工作之**攸關性、合理性、適切性**。
- **不得於查核報告中提及**查核人員專家之工作（除非法令要求；若提及須加註「不減輕會計師責任」）。
- 查核人員雖非該領域專家，可透過先前經驗/教育對該領域取得足夠了解而**無須**專家協助。

## 必背速記
- 五要素前三間接（整體）、後二直接（個別聲明）
- 付諸實行 ≠ 執行有效（後者靠控制測試）
- ITGC 支撐應用控制；高度自動化須測 IT 控制
- 顯著缺失應書面通知治理單位；不得保證無其他缺失
- 專家工作不減輕責任；評估能力/客觀/適切；原則不於報告提及
