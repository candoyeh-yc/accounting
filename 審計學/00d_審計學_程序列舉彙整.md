# 審計學｜「列舉程序」彙整卡（申論列舉題素材庫）

> 審計申論最愛考「**列舉 X 項程序**」。本卡把各準則的程序清單收一起，蓋住右邊默寫。詳細解說點連結回深掘。

---

## 一、舞弊／風險相關

**① 管理階層踰越控制（240）★必背** → [13](13_審計學_深掘_舞弊240.md)
1. 測試**日記簿分錄**及編表所作其他調整之適當性
2. 複核**會計估計**有無偏頗
3. 了解**不尋常/非常規重大交易**之商業理由
> 不論評估高低都做（存在於所有受查者、難預測）。⚠ 別跟「顯著風險因應」混。

**② 風險評估程序之方法（315）** → [06](06_審計學_深掘_查核程序與證實程序.md)
査詢、分析性程序、觀察及檢查（**不含外部函證**）

**③ 顯著風險之特別因應（330）** → [06](06_審計學_深掘_查核程序與證實程序.md)
1. 了解與該風險攸關之控制
2. 擬信賴控制 → **當期**測試
3. 特別針對該風險之證實程序
4. 僅證實程序因應 → **須含細項測試**

**④ 取得查核證據七方法（500）** → [06](06_審計學_深掘_查核程序與證實程序.md)
**檢、觀、函、算、做、問、析**

---

## 二、特定科目

**⑤ 存貨實體盤點（501）** → [08](08_審計學_深掘_會計估計與存貨盤點.md)
1. 評估管理階層盤點**指示與程序**
2. **觀察**盤點執行
3. **檢查**存貨
4. **抽盤測試**（紀錄→實體＝存在；實體→紀錄＝完整）

**⑥ 會計估計四對策（540）** → [08](08_審計學_深掘_會計估計與存貨盤點.md)
1. 期後事項是否提供證據
2. 測管理階層**怎麼估**（資料/假設/方法）
3. 測相關**控制**
4. 自建**區間估計**

**⑦ 關係人「未告知而發現」之額外實質程序（550）** → [09](09_審計學_深掘_集團查核關係人訴訟法令.md)
查詢性質／檢查文件／評估**商業理由**／確認授權／向對方**函證**／驗證**公平交易條件**／確認揭露

---

## 三、訴訟、結案

**⑧ 訴訟與索賠之辨認程序（501）** → [09](09_審計學_深掘_集團查核關係人訴訟法令.md)
1. 查詢管理階層及內部法務
2. 複核**治理單位會議紀錄**及與外部律師往來文件
3. 複核**法律費用**科目
（＋與外部法律顧問**直接溝通**；拒絕→範圍限制→保留/無法表示）

**⑨ 繼續經營之因應程序（570）** → [11](11_審計學_深掘_規劃函證期後結案.md)
1. 要求管理階層**執行評估**
2. 評估其**因應計畫**之可行性
3. 檢視**現金流量預測**之資料與假設
4. 取得**書面聲明**

**⑩ 完成階段程序（560 等）** → [11](11_審計學_深掘_規劃函證期後結案.md)
查找**未入帳負債**／**律師函證**／複核**董事會會議紀錄**／**整體分析性**複核（＋書面聲明）

**⑪ 外部函證未回函/拒絕之替代程序（505）** → [06](06_審計學_深掘_查核程序與證實程序.md)
- 應收帳款：查**期後收款**、送貨單、接近期末銷貨
- 應付帳款：查**期後付款**、與供應商往來/對帳單

---

## 用法
- 申論看到「**列舉 N 項…程序**」→ 先定位是上面哪一條 → 默寫該清單。
- 每天蓋住右欄默寫 2-3 條，輪流刷。
- ⚠ 最易混：**④管理階層踰越控制（240）vs ③顯著風險因應（330）**——前者測分錄/估計/非常規交易，後者測控制/細項測試。
