# A 區｜記憶口訣（清單硬記・中英雙軌）

## ① QM1 品質管理八要素　｜碼：**AGEEERCM**
- **A** 風險評估流程　- **G** 治理及領導　- **E** 職業道德　- **E** 承接及續任　- **E** 案件執行　- **R** 資源　- **C** 資訊與溝通　- **M** 監督及改善

**邏輯鉤**：A 頭（風險評估引擎）＋ M 尾（監督回饋）；中間**三個 E（道德／承接／執行）＋資源＋溝通**＝實質工作。「A 頭 M 尾、三 E 夾中間」。

## ② QM2 案件品質複核 EQR（4 重點）
**局外人**（非團隊成員）在**報告日前**、對團隊**重大判斷**做**客觀評估**；有疑慮→不出報告。

## ③ 獨立性 五威脅　｜碼：**IRAFI**
**I** 自我利益　**R** 自我評估　**A** 辯護　**F** 熟悉度　**I** 脅迫。鉤：**兩個「自我」＋辯、熟、脅**。

## ④ 固有風險因子（5）　｜碼：**CSFUM**
**C** 複雜性　**S** 主觀性　**F** **變動**（⚠官方用「變動」非「變動性」，§315-11-6）　**U** 不確定性　**M** 易受管理階層偏頗或舞弊。鉤：越「複、主、變、不、弊」→ 固有風險越靠光譜上端。

## ④-1 固有風險光譜位置（除因子外再考量2項）
除固有風險**因子**影響程度外，尚考量：**不實表達發生之①可能性 ②重大程度（金額大小）**。

## ⑤ 顯著風險 常見當然 3 項　｜碼：**MRR**
**M** 踰越控制舞弊　**R** 重大關係人交易　**R** 收入認列舞弊。鉤：兩個舞弊＋一個關係人。（定義：固有風險近光譜頂端，或他準則規定視為顯著。）

## ⑤-1 舞弊三角（三要素・為何會舞弊）　｜碼：**IOA**
**I** 誘因／壓力（Incentive/pressure，獲利目標/財務困難/紅利連動）　**O** 機會（Opportunity，內控薄弱/可踰越控制）　**A** 態度／合理化（Attitude/rationalization，「只是暫借」「公司本來就欠我」）。
鉤：**有壓力＋有機會＋還要一套說服自己的說法**。舞弊 vs 錯誤＝有無**故意**。

## ⑥ 不實表達 三類別（450）　｜碼：**FJP**
**F** 實際（明確金額，§17 用「實際」非「明確」）　**J** 判斷性（估計不合理/政策不當）　**P** 推估（抽樣推估）。

## ⑦ 重大性 三層（320）
**整體**（基準×%，稅前淨利）＞ **執行**（必更低）＞ **特定**。「整＞執＞特」。

## ⑧ 證實程序 三鐵律
每一重大科目都做、**顯著風險必含細項測試**、財報勾稽＋重大分錄。

## ⑨ 風險評估程序 三方法（315）
**查、析、觀**（查詢／分析性／觀察及檢查）；**不含外部函證**。

## ⑩ 內控 五要素（間接3／直接2）
間接3＝**環、評、監**（整體財報層級）；直接2＝**訊、作**（個別聲明層級）。「環評監／訊作」。

## ⑪ 會計估計 四對策（540）　｜碼：**SMCD**
**S** 期後事項提供之證據　**M** 測管理階層怎麼估（資料/假設/方法）　**C** 測相關控制　**D** 自建區間/單一金額估計。
**顯著風險額外評估**：替代假設、假設合理性、意圖與能力、揭露 →「替、理、意、露」。

## ⑫ 確信案件（3000）　｜五要素碼：**3SCER**
**3** 三方關係　**S** 標的　**C** 基準　**E** 證據　**R** 確信報告。
**基準五特性**：攸關、完整、可靠、中立、可瞭解 →「攸、完、靠、中、瞭」。
鉤：合理確信＝積極式（…允當表達）；有限確信＝消極式（並未發現…）。

## ⑬ 存貨盤點 四程序（501）
評估盤點指示、觀察執行、檢查存貨、抽盤測試。方向鉤：**紀錄→實體＝存在；實體→紀錄＝完整性**。

## ⑭ 查核報告意見（決策口訣）
先判**原因**（未更正不實＝意見分歧／無法取證＝範圍限制），再判**程度**（不廣泛→保留／廣泛→否定 or 無法表示）。配對鉤：意見分歧＋廣泛＝**否定**；範圍限制＋廣泛＝**無法表示**。

## ⑮ 取得查核證據 七方法（500）　｜口訣：**檢、觀、函、算、做、問、析**
檢查／觀察／函證／重新計算／重新執行／查詢（**單獨不足**）／分析性。
易混：重新**計算**＝只驗數字；重新**執行**＝整個控制/程序再做一遍。可靠性：外部＞內部、書面＞口頭、原本＞影本。

## ⑯ 準則制定機構　｜口訣：國際看字母（E=道德、AA=審計）
我國道德→會計師**公會**全國聯合會；我國審計/會計準則→會計**研究發展基金會**；國際道德→I**E**SBA；國際審計確信→I**AA**SB；美國→**A**ICPA。陷阱：IAASB↔IESBA 對調，看字母 E/AA 破解。

# B 區｜列舉程序（申論「列舉 N 項程序」素材庫）

**① 管理階層踰越控制（240）★不論風險高低都做** → [13](13_審計學_深掘_舞弊240.md)
1. 測試**日記簿分錄**及編表其他調整之適當性　2. 複核**會計估計**有無偏頗　3. 了解**不尋常/非常規重大交易**之商業理由
> ⚠ 別跟「顯著風險因應（330）」混：這裡測分錄/估計/非常規交易。

**② 顯著風險之特別因應（330）**
1. 了解與該風險攸關之控制　2. 擬信賴→**當期**測試控制　3. 針對該風險之證實程序　4. 僅證實因應→**須含細項測試**

**③ 存貨實體盤點（501）** → [08](08_審計學_深掘_會計估計與存貨盤點.md)
評估盤點**指示與程序**／**觀察**執行／**檢查**存貨／**抽盤測試**（紀錄→實體＝存在；實體→紀錄＝完整）

**④ 會計估計四對策（540）** ＝ 口訣 SMCD（期後事項／測怎麼估／測控制／自建區間）

**⑤ 關係人「未告知而發現」之額外實質程序（550）** → [09](09_審計學_深掘_集團查核關係人訴訟法令.md)
查詢性質／檢查文件／評估**商業理由**／確認授權／向對方**函證**／驗證**公平交易條件**／確認揭露

**⑥ 訴訟與索賠之辨認程序（501）★連兩年考** → [09](09_審計學_深掘_集團查核關係人訴訟法令.md)
1. 查詢管理階層及內部法務　2. 複核**治理單位會議紀錄**及與外部律師往來文件　3. 複核**法律費用**科目
> ⚠ **律師函證/直接溝通屬「辨認後」之程序（§9-10），不列入辨認三程序**（113/114 連錯點）。拒絕溝通→範圍限制→保留/無法表示。

**⑦ 繼續經營之因應程序（570）** → [11](11_審計學_深掘_規劃函證期後結案.md)
要求管理階層**執行評估**／評估**因應計畫**可行性／檢視**現金流量預測**資料與假設／取得**書面聲明**（＋評估揭露適當性）

**⑧ 完成階段程序（560等）**
查**未入帳負債**／**律師函證**／複核**董事會會議紀錄**／**整體分析性**複核／取得**書面聲明**

**⑨ 外部函證未回函之替代程序（505）** → [06](06_審計學_深掘_查核程序與證實程序.md)
- 應收帳款：查**期後收款**、送貨單、接近期末銷貨　- 應付帳款：查**期後付款**、供應商對帳單

**⑩ 內稽採用前之評估（610）** → [07](07_審計學_深掘_內部控制與專家工作.md)
評**客觀性**（組織地位/報告對象）／**專業能力**／**系統化且嚴謹之方法**（含品管政策）；採用後須**重新執行部分**。

**⑪ 專家工作之評估（620）**
評**專業能力×適任能力×客觀性** ＋ 工作之**攸關性/合理性/適切性**；採用**不減輕**查核人員責任。

**⑫ 分析性程序 三階段（520）★易漏、第10回扣分** → [14](14_審計學_深掘_分析性程序520.md)
①規劃/風險評估（315，**強制**）＝辨認 RMM 找風險；②證實分析性（520，**選用**）＝偵聲明層級錯誤、取證；③整體性評估（520.6，**強制**）＝結論前看財報整體與了解是否一致。
> 證實分析性目的＝**偵錯取證，非辨認 RMM**（別污染）。**520.5 使用四條件**：聲明適合／資料可靠／預期值夠精確／訂可接受差異金額。

**⑬ 與治理單位溝通 四事項（260）★申論常考「應溝通事項」** → [11](11_審計學_深掘_規劃函證期後結案.md)
1. 查核人員之**責任**（形成表示意見、不減輕管理/治理責任）　2. 所規劃**查核範圍及時間**概要　3. 查核之**重大發現**（會計政策/估計/揭露品質、重大困難、要求之書面聲明）　4.（**上市櫃**）**獨立性**——第19條：獨立性溝通**以書面**。
> 鉤：責任、範圍時間、重大發現、（上市櫃）獨立性書面。

**⑭ 舞弊之整體層級因應（240）** → [13](13_審計學_深掘_舞弊240.md)
指派**更有經驗/專業人員**／加強**專業懷疑**／增加查核**不可預測性**／加強**督導**／評估會計政策選擇有無偏頗。

**⑮ 集團查核團隊之參與（600，重要組成個體/顯著風險）** → [09](09_審計學_深掘_集團查核關係人訴訟法令.md)
1. 評估組成個體查核人員之**能力/獨立性/工作品質**　2. **參與其風險評估**、討論商業活動與顯著風險　3. 對顯著風險**自行執行或指示**特定程序　4. **複核其工作底稿**（顯著風險/重大判斷）　5. 要求其**溝通重大發現**與獨立性聲明　6. 評估證據是否足夠、不足追加。
> 「提及」組成個體查核人員＝**分割責任**：須通知＋（指名）取得同意＋報告一併列報（對比專家不得提及、永不減輕責任）。

**⑯ 關係人之查核程序（550）** → [09](09_審計學_深掘_集團查核關係人訴訟法令.md)
1. 向管理階層**查詢**關係人身分/交易/有無未揭露　2. 了解**辨認、授權、會計處理**關係人交易之控制　3. 對辨認之交易：檢查合約、**評估商業理由**、確認金額與揭露、必要時**函證**對方　4. 重大非常規交易保持**高度專業懷疑**。

**⑰ 法令遵循之責任（250）** → [09](09_審計學_深掘_集團查核關係人訴訟法令.md)
- **直接影響**財報金額/揭露之法令（如租稅、退休金）→ **取得足夠適切證據**確認遵循。
- **其他法令**（營運許可、環保等）→ 特定程序：①**查詢管理階層** ②**檢查與發證/主管機關往來函件**（不背書其遵循）。
> 辨認未遵循→了解性質/評估影響→**溝通治理單位**（第22條，除非法令禁止或顯然微不足道）；**不得為保密而不溝通**。

**⑱ 委任書必載 五項（210）** → [11](11_審計學_深掘_規劃函證期後結案.md)
查核**目標與範圍**／會計師**責任**／管理階層**責任**／適用**財報導架構**／查核報告**預期形式**。
> 先決條件：①架構可接受 ②管理階層認知三責任（編表、維持內控、提供接觸資訊）。

**⑲ 整體查核策略 五考量（§7）／查核計畫 四內容（§8）（300）** → [11](11_審計學_深掘_規劃函證期後結案.md)
- **策略**（範圍時間方向資源）：①界定範圍之案件特性 ②報告目標與時間/溝通 ③影響努力方向之重要因素（重大性/初步風險/內稽） ④初步查核活動結果 ⑤**所需資源**性質時間範圍。
- **計畫**（把策略化為程序）：①**指導、監督及複核**（最易漏）②風險評估程序 ③進一步查核程序（聲明層級）④其他符合準則之程序。

**⑳ 消極式函證 使用四條件（505 §14）**
①RMM 低**且已測相關控制有效** ②大量、小額之科目餘額 ③預期例外率低 ④無理由相信受函者會漠視。

# C 區｜流程與處置（★★★ 順序性 & 「遇到狀況怎麼辦」──最易漏，申論常扣）

## 【處置一】管理階層拒絕更正不實表達之因應（450）★順序性 → [03](03_審計學_深掘_重大性與450不實表達評估.md)
> 口訣：**拒 → 問因 → 評重大性 → 報治理 → 取聲明 → 定意見（＋顧前期）**
1. **了解拒絕原因**，並重新考量該不實表達是否確實存在。
2. **重新評估財務報表整體重大性**是否仍屬適當（規劃用預估、期末有實際數，須校準；門檻可能調降→追加程序）。
3. 將**所有未更正不實表達**單獨及彙總，**與治理單位溝通**並請其更正。
4. 取得管理階層（及治理單位）**書面聲明**：說明其認未更正不實表達單獨及彙總不重大之理由（附未更正彙總表）。
5. **評估**未更正單獨或彙總**是否重大** → 重大則影響意見（**重大不廣泛→保留；重大且廣泛→否定**）。
6. 考量未更正不實表達對**前期（對應數字）**之影響。
> ⚠ ③「重新評估」要點名**重大性**；④對象是**治理單位**（升級，非重複管理階層）；書面聲明≠決定意見（會計師自己判斷）。

## 【處置二】抽樣推估不實表達 ＞ 可容忍不實表達之後續（530）★易漏 → [10](10_審計學_深掘_審計抽樣.md)
1. 要求**管理階層調整**（更正不實表達）。
2. **擴大樣本**或執行**追加／替代查核程序**。
3. **重新評估**重大不實表達風險與查核策略（必要時提高證實程序之性質/時間/範圍）。
> ⚠ 別停在「推估 800 萬 ＞ 可容忍 600 萬」重述結果──**超標一定要寫「下一步做什麼」**。
> **部分更正後**：剩餘推估不實**不能直接跟可容忍比**，須「彙總未更正不實表達→與**重大性**比→重大不廣泛保留/重大且廣泛否定」。

## 【處置三】樣本錯誤集中於特定客群/區段（530）
1. 評估是否為**系統性（非隨機）錯誤**，不宜逕推論為隨機分布。
2. 對該群體**分層（stratify）**並執行**追加測試**。
3. 必要時重估該分層 RMM／重新設計母體與抽樣方法。

## 【處置四】管理階層拒絕查核人員寄發詢證函（505）★順序性 → [06](06_審計學_深掘_查核程序與證實程序.md)
> 重點：**不是立刻改替代程序**，先查合理性再說。
1. **查詢管理階層拒絕之理由**，並取得證據**評估其合理性與正當性**。
2. 評估拒絕對**RMM（含舞弊風險）之影響**，及對其他查核程序性質/時間/範圍之影響。
3. **執行替代查核程序**以取得攸關可靠證據。
4. 若管理階層拒絕**不合理**、或替代程序**無法取得足夠適切證據** → 視為**查核範圍限制** → 與治理單位溝通，並依程度出**保留／無法表示意見**。

## 【處置五】積極式詢證函「回函不符」之處理（505）
查明**所有不符之原因** → 判斷是否為**不實表達**（可能是時間差/付款在途，也可能是真差異）→ 必要時追加程序。

## 【處置六】內部控制顯著缺失之溝通（265）
- **顯著缺失**：**書面、及時**溝通**治理單位（及管理階層）**；一般缺失得口頭對管理階層。
- 內容：缺失描述、可能影響、查核目的限制；**不得**出具「未辨認出其他缺失」之保證。
- 拒絕改善不直接導致修正式意見；仍看是否造成重大不實或無法取證、及是否重大且廣泛。

## 【處置七】其他資訊 vs 財報 須修正而拒絕（720/705）
- **財報**須修正而拒絕 → 影響意見（**保留/否定**）。
- **其他資訊**須修正而拒絕 → **不影響查核意見**，但於報告中**強調**該情事或採其他措施（台灣 720 **無「其他資訊段」**，別寫錯段名）。

## 【處置八】分析性程序差異超過可接受差異（520.7）→ [14](14_審計學_深掘_分析性程序520.md)
1. **查詢管理階層**（差異可能有合理商業解釋）。
2. 不能只信口頭 → **取得佐證證據**評估其合理性。
3. 仍無法解釋 → **執行其他必要查核程序**（通常轉細項測試）。
> 對比抽樣超標（處置二）：**分析性超線先「問人」（可能沒事）；抽樣超線先「查錯」（已經有事）**。

## 【處置九】書面聲明不可靠或拒絕提供（580）
對管理階層誠信存疑致書面聲明**不可靠**、或管理階層**拒絕提供**必要書面聲明 → 影響廣泛 → 可能出具**無法表示意見**。

## 【順序一】整個查核案件之執行順序（114-測10）→ [11](11_審計學_深掘_規劃函證期後結案.md)
①評估**職業道德/獨立性** → ②簽**委任書** → ③了解受查者、**評估 RMM** → ④**控制測試** → ⑤（結案前）取得**書面聲明**。

## 【順序二】查核風險模式之決策順序（113-測12）
先**訂定可接受查核風險 AR** → 評估**固有風險 IR、控制風險 CR** → 推算**可容忍偵查風險 DR** → 據以決定查核程序之性質時間範圍。（AR、DR 反向：DR＝AR÷(IR×CR)）

## 【順序三】審計抽樣之進行順序（112-測13）
①設定**查核測試目標** → ②**定義屬性及偏差情況** → ③設定**可容忍偏差率** → ④**挑取樣本**（執行程序）→ ⑤**分析偏差原因**。

## 【順序四】期後事項五個關鍵日期（560）→ [11](11_審計學_深掘_規劃函證期後結案.md)
```
期末 ── 財報核准日 ── 取得充足證據日 ── 查核報告日（★錨點）── 財報發布日
        (董事會核准)   (證據齊備)                              (交付第三者)
               書面聲明日 ┘（≤ 查核報告日）
```
- 查核報告日 ≥ 取得充足證據日 ≥ 財報核准日；書面聲明日**不得晚於**查核報告日。
- 期末～報告日之重大期後事項→**主動**調整/揭露；報告日後**無主動查核義務**（但獲悉重大事實仍須處理）。

## 【順序五】首次受託之期初餘額取證（510）→ [11](11_審計學_深掘_規劃函證期後結案.md)
1. 對重要**期初科目餘額與上期交易**執行適當查核程序。
2. **向前任會計師查詢**。
3. **借閱前任會計師工作底稿**。
> ⚠「詢問管理階層品德」＝承接評估事項、**非**期初餘額取證方式。

## 【順序六】管理階層拒絕評估繼續經營能力（570）
→ 屬**範圍限制** → 要求管理階層評估；仍拒絕 → 依影響程度出**保留／無法表示意見**。
