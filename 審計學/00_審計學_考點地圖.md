> 出處標記：`年-申X`＝該年第X申論題；`年-測X`＝該年測驗第X題

## 四、⚠ 時效性總表（審計學最大陷阱）

我國審計準則於 110–112 年完成「兩位數舊編號 → 三位數新編號（與 ISA 一致）」改版。**用 110、111 年舊題複習時，務必對照新號與新內容。**

| 舊編號 | 新編號 | 主題 |
|---|---|---|
| 第54號 | **600** | 集團財務報表查核 |
| 第56號 | **540** | 會計估計與相關揭露之查核 |
| 第57號 | **700/705/706** | 查核報告、修正式意見、強調事項與其他事項 |
| 第63號 | **510** | 首次受託—期初餘額 |
| 第66號 | **580** | 書面聲明 |
| 第43號 | **450** | 查核過程中所辨認不實表達之評估 |
| 第75號 | **315** | 辨認並評估重大不實表達風險（**大改版**） |
| 第46號／品管1、2號 | **品質管理準則 QM1、QM2** | 事務所品質管理＋案件品質複核（管制→管理、風險導向） |

**315 號改版重點**（112–114 密集出題的送分／陷阱區）：新增「固有風險因子」「固有風險光譜」「僅執行證實程序無法取得足夠及適切證據之風險」。

## 五、📈 115 年（今年）預測考點

> 依五年出題輪替與未考/久未考點推估，僅供配重，仍須全面準備。

**申論高機率（重點押這幾題型）**
1. **查核報告意見類型**——自 110 年後已 4 年未出申論，輪替到頂，**強烈預期回歸申論**（搭配 KAM、繼續經營不確定性段）。
2. **品質管理 QM1/QM2**——新制改版剛上路，114 才首度入測驗，**極可能升級為申論**（事務所品質管理八要素 / 案件品質複核人員職責）。
3. **315 號 RMM**——連三年熱點，固有風險光譜/顯著風險仍可能再出。
4. **舞弊（240 號）**——近年只在測驗點到，申論久未深考，屬潛在冷門爆點（管理階層踰越控制、舞弊三要素）。

**測驗幾乎必出（背熟穩拿）**
- 專家工作（620）——五年每年都出，今年大概率續出
- 內部控制組成要素 / 缺失溝通（265）
- 重大性與質性因素（320）
- 獨立性與職業道德（道德規範第10號）
- 確信案件 合理 vs 有限確信（3000）
- 審計抽樣（含一題計算，留意平均數估計法）

**時效性必清**：QM1/QM2 新制、315 改版用語、三位數新編號——舊題答案凡涉舊號舊制，一律改用新版。
