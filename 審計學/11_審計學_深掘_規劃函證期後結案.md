# 審計學 深掘⑪｜查核流程：規劃與結案（210/300/560/570/580）★★

> 查核流程的「頭（規劃）」與「尾（結案：期後/繼續經營/書面聲明）」框架性程序。
> （函證已移至 [06 查核程序與證實程序](06_審計學_深掘_查核程序與證實程序.md)，與取證方法同處。）

## 一、查核委任與規劃（210／300）
- **委任書（210）**必載（第八條，5 項）：查核目標與範圍、會計師之責任、管理階層之責任、適用財報架構、**查核報告之預期形式**。
- **查核先決條件（210 第四條）**：①**財報導架構可接受** ②取得管理階層**認知其三項責任**（編製財報、維持必要內部控制、提供查核人員接觸資訊）之同意。（210 於 113/4/2 修訂、與 TWSA220 同時適用。）
  > 「預期形式」＝先講好會出**哪種報告**（通常是對財報表示意見之查核報告）＋**聲明可能因情況與預期不同**（即**不保證無保留意見**，可能出修正式意見）。作用：管理客戶期待、保護會計師、**防脅迫威脅**（客戶不能事後主張「你答應給乾淨意見」）。
- **整體查核策略 vs 查核計畫（300）★申論可能考「策略之內容／考量事項」**：

  | | 整體查核策略 | 查核計畫 |
  |---|---|---|
  | 層級 | 高層、決定範圍時間方向、**資源配置** | 細部，擬執行之**程序**之性質時間範圍 |
  | 性質/時間/範圍修飾誰 | **資源**（策略，**第七條**e）| **查核程序**（計畫，**第八條**）|
  | 先後 | 先 | 後（依策略展開）|
  | 動態性 | 規劃初期定調 | ⚠ **第九條：策略與計畫兩者**均於整個查核過程中**適時更新及修改**（113-測2）|

  > ⚠**條號**：台灣 TWSA300 是**第七條（策略）／第八條（計畫）／第九條（兩者持續更新）**——**不是** ISA 的 300.8/300.9，申論引條號別寫成 8/9。

  **① 整體查核策略之「內容／考量事項」（第七條，五項）**——決定查核的**範圍、時間、方向、資源**：
  1. 辨認**案件特性以界定查核範圍**（財報導架構、產業別法規、集團與組成個體）。
  2. 確定案件之**報告目標**，以規劃查核**時間**及所需**溝通**之性質。
  3. 考量在專業判斷上**影響查核團隊努力方向之重要因素**（重大性、初步風險評估、內部稽核可利用性、重大商業/會計發展）。
  4. 考量**初步查核活動之結果**（承接/續任程序），及以往其他案件所得知識是否攸關。
  5. 確定執行案件**所需資源之性質、時間及範圍**（人力配置與經驗、是否用專家、預算、時程）。

  **② 查核計畫之「內容」（第八條，四項）**——把策略**具體化為程序**：
  1. ⭐**對查核團隊成員之指導、監督及對其工作複核**之性質、時間及範圍（**最易漏的第(1)款**）。
  2. **風險評估程序**之性質、時間及範圍（315）。
  3. **進一步查核程序**之性質、時間及範圍——**聲明層級**（330，含控制測試＋證實程序）。
  4. 其他為使案件**符合審計準則**所須執行之查核程序。

  **③ 兩者關係**：策略**先定調（框架、方向、資源）→ 計畫依策略展開（細部程序）**；兩者**互動、非線性**，可隨查核進展與新資訊**持續修正**（不是策略定完就不動）。

  > ⚠ **兩個常考陷阱**：①「**指派具經驗成員負責高風險項目／專家參與複雜事項**」＝**資源配置＝策略（第七條e）**，別歸到計畫（113-測2 D 錯）。②「規劃應於**整個查核過程持續進行/更新**」＝**正確**（第九條：**策略與計畫兩者都更新**，別誤解「策略只在初期定調」）。
  > **口訣：策略管「範圍時間方向＋資源」（先、粗、第七條五項）；計畫管「程序」（後、細、第八條四項，第一項＝指導監督複核）。**
- 查核程序之執行順序（114-測10）：①評估職業道德/獨立性 → ②簽委任書 → ③了解受查者評估 RMM → ④控制測試 → ⑤取得書面聲明（結案前）。

## 一之一、與治理單位溝通（260）★（申論常考「應溝通事項」）
四大應溝通事項（皆有條號）：
1. **第十三條**：查核人員對財報查核之**責任**（形成並表示意見；不減輕管理/治理責任）。
2. **第十四條**：所規劃之**查核範圍及時間**概要。
3. **第十五條**：查核之**重大發現**（會計政策/估計/揭露之品質、查核所遇重大困難、要求之書面聲明、其他重大事項）。
4. **第十六條**：（**上市櫃**）查核人員之**獨立性**——且**第十九條：獨立性之溝通應以「書面」為之**。
> 口訣：**責任、範圍時間、重大發現、（上市櫃）獨立性書面**。

## 二、期後事項（560）
- **兩類期後事項**：①需調整（資產負債表日已存在之情況）；②僅需揭露（之後發生）。

### ★ 五個關鍵日期的關係（時間軸）
```
期末              財報核准日 ── 取得充足證據日 ── 查核報告日 ─────── 財報發布日
(資產負債表日)     (董事會核准、    (證據齊備，已含     (★錨點日)        (交付第三者)
   │              承擔責任)        財報已編妥+核准)      ▲
   │←─ 期後事項期間：會計師「主動」調整/揭露 ─→│       │
                                   書面聲明日 ──────────┘
                            (盡量接近、但不得晚於報告日)
```
| 規則 | 依據 |
|---|---|
| **查核報告日 ≥ 取得充足證據日**（報告日不得早於證據齊備）| 700 |
| **查核報告日 ≥ 財報核准日**（「取得充足證據」本身含「財報已編妥+經有權者核准負責」）| 700/560 |
| **財報核准日 ≤ 取得充足證據日 ≤ 查核報告日**（常同日或相近，順序固定）| — |
| **書面聲明日 ≤ 查核報告日**（盡量接近、但不得晚於）| 580 |
| **重大期後事項**（期末～查核報告日）→ 會計師**主動**調整/揭露 | 560 |

> 核心：**查核報告日是錨點**，往前要等「證據齊備＋財報核准」都到位；書面聲明貼著報告日（剛好或稍早）。
- **報告日後、財報發布前**獲悉事實：與管理階層討論、決定是否修改財報；若修改 → 對新增事項執行程序並更新報告日（或雙簽日期）。
- **財報發布後**獲悉事實：若該事實於報告日已存在且重大 → 與管理階層討論是否修改、必要時防止信賴原財報。
- 查核報告日後查核人員**無主動執行查核程序之義務**。

## 三、繼續經營（570）（與 01 篇互補）
- 管理階層責任：評估繼續經營能力（至少自財報日起 12 個月）。
- 查核人員：評估其評估、辨認重大不確定性之事件/情況（淨損、負債大於資產、重要客戶流失、供應商改現金交易等）。
- 因應程序：要求管理階層評估、評估其因應計畫之可行性、檢視現金流量預測之資料與假設、取得書面聲明。
- 意見對應見 [01 查核報告意見](01_審計學_深掘_查核報告意見.md) 第四節（已揭露→無保留＋專段；基礎不適當→否定）。

**★ 考試重點（依序）**
1. **四情況→意見**：基礎不適當→**否定**；有重大不確定性且**已揭露**→**無保留＋專段**；揭露不足→保留/否定；不願評估→保留/無法表示。
2. ⭐**最大陷阱**：「**與繼續經營有關之重大不確定性」段 ≠ 強調事項段**——是 570 之**獨立專段**，已揭露時意見仍**無保留**（別答成強調事項段或保留意見）。
3. **數字 12 個月**：管理階層評估期間至少自財報日起 12 個月；**不足→會計師要求延長**。
4. **情境題抓警訊**：淨損、負債>資產、無法償債/融資、**供應商改現金交易**、關鍵人員離職、流失重要客戶。
> 只記兩件就好：①「四情況→意見」表、②「專段≠強調事項段」。

## 四、書面聲明（580）
- 用途：管理階層確認已履行編製財報、提供完整資訊之責任；**自身無法提供足夠適切證據**，但屬必要查核證據。
- **日期**：儘量接近、但**不得晚於**查核報告日；應涵蓋報告所提及之所有財報與期間。
- 限制性文字：某些情形得用「就本公司所知」。
- 書面聲明**不可靠或拒絕提供** → 影響廣泛 → 可能出具**無法表示意見**。

## 五、首次受託—期初餘額（510，舊63）★★（110-測13、114-測14）
- **取證方式**：①對重要**期初科目餘額與上期交易**執行適當查核程序；②**向前任會計師查詢**；③**借閱前任會計師工作底稿**。⚠「**詢問管理階層品德**」＝承接評估事項、**非期初餘額取證方式**（114-測14 答 C）。
- **意見對應**（110-測13）：
  | 情況 | 意見 |
  |---|---|
  | 期初餘額**無法取得**足夠適切證據（範圍限制）| **保留或無法表示** |
  | 期初餘額存有**重大不實表達**且未適當處理 | **保留或否定** |
  | 會計政策**變動**未適當處理/揭露 | **保留或否定** |
  | ⚠ 陷阱：上述情形出「附強調事項段之無保留」＝**錯** | — |
- 上期由前任查核且保留原因**延續影響本期** → 本期亦出保留/否定（110-測21 併考）。

## 六、查核工作底稿（230）★（112-測6）
- **保管年限起算日＝查核報告日**（第三十八條；非資產負債表日、非歸檔日；112-測6 答 B），**保存不短於 5 年**；集團看較晚之集團報告日。
- **歸檔期限（第三十六條）**：通常於查核報告日後**六十天內**完成彙整歸檔；歸檔後（第十五條）保管期限屆滿前**不得刪除或銷毀**。
- 歸檔：查核報告日後**60 日內**完成最終檔案彙整；歸檔後**不得刪除**，僅得依規定新增/註記。

## 必背速記
- 委任書必載會計師/管理階層責任、範圍、架構、報告形式
- 期初餘額三取證：查期初科目＋問前任＋借底稿；「問品德」不是
- 工作底稿保存自**查核報告日**起算；60 日內歸檔
- 整體策略（高層先）vs 查核計畫（細部後）；公費非主要規劃因素
- 期後：報告日不早於取證日、書面聲明不晚於報告日；發布後獲悉重大事實須處理
- 書面聲明不晚於報告日；拒絕提供→可能無法表示意見
