# 審計學 深掘①｜查核報告意見類型（700／705／706）★★★

> 申論主力，自 110 年後久未出申論，115 年高機率回歸。本篇＝完整決策邏輯＋段落結構＋實際考題解題。
> 對應準則：700（查核報告）、705（修正式意見）、706（強調事項段與其他事項段）、570（繼續經營）、701（關鍵查核事項 KAM）

---

## 一、核心決策樹（背到能反射）

修正式意見只有兩個觸發原因，先定性、再定程度：

```
Step1 判「原因」
  ├─ 財務報表有不實表達且未更正（意見分歧）→ 走 A 線
  └─ 無法取得足夠及適切查核證據（範圍限制）→ 走 B 線

Step2 判「重大程度」
  A 線（意見分歧）
     ├─ 重大但不廣泛 → 保留意見（qualified）
     └─ 重大且廣泛   → 否定意見（adverse）
  B 線（範圍限制）
     ├─ 重大但不廣泛 → 保留意見（qualified）
     └─ 重大且廣泛   → 無法表示意見（disclaimer）
```

**「廣泛（pervasive）」三判準**（705）：①不限於財報特定要素/科目；②即使侷限，卻占財報重大或大部分比例；③對揭露而言，係使用者理解財報所不可或缺。

| 情況 | 不重大 | 重大但不廣泛 | 重大且廣泛 |
|---|---|---|---|
| 意見分歧（有不實表達）| 無保留 | **保留** | **否定** |
| 範圍限制（無法取證）| 無保留 | **保留** | **無法表示** |

## 二、查核報告段落結構（700）與修正時改哪段

標準無保留查核報告段落順序：
1. **查核意見段**（標題即「查核意見」）
2. **查核意見之基礎段**
3. （上市櫃）**關鍵查核事項段 KAM**
4. 其他事項（強調事項段／其他事項段，如有）
5. 管理階層與治理單位之責任段
6. 會計師查核財務報表之責任段

**出修正式意見時「內容」須修改的段落（不含標題）**：
- **查核意見段 + 查核意見之基礎段**（兩段必改）；**上市公司另含「關鍵查核事項段」**（導致修正之事項移至基礎段、不在 KAM 段重複，故 KAM 段內容也變——113-測23 答 B）
- 無法表示意見時：查核意見段文字「財務報表業經查核」改為「**本會計師受委任查核**」；責任段相應簡化（**§27**：僅敘明執行查核並出具報告＋因基礎段事項無法取得足夠適切證據＋獨立性聲明）。
  > ⚠**705 兩個「不得」（§25，無法表示意見之意見基礎段）**：①**不得提及**「會計師查核財務報表之責任段」；②**不得敘明**「已取得足夠及適切之查核證據」。這兩句是常考細節。
- 否定/保留：基礎段須具體敘明不實表達之內容與金額（可量化時）

> 113-測23 考點（**已更正**）：上市公司出保留意見，相對無保留，須修改「**查核意見段＋查核意見之基礎段＋關鍵查核事項段**」（**官方答案 B**）。**非上市（無 KAM）才只改意見段＋基礎段兩段。**
> ⚠**701 精確機制（§11＋§14，別寫成「移走/不列」）**：導致修正意見之事項「本質上即為 KAM」，會計師**仍須於 KAM 段敘明該事項、並「索引」至保留意見之基礎段**（§14）；只是**不於 KAM 段「溝通」該事項之細節**（§11，細節在基礎段）。所以 KAM 段內容會變＝多一筆「交叉索引」，不是把它整個拿掉。

## 三、強調事項段 vs 其他事項段 vs KAM（最易混淆，必背對照）

| | 強調事項段（706）| 其他事項段（706）| 關鍵查核事項段（701）|
|---|---|---|---|
| 內容是否已在財報揭露 | **已適當揭露**於財報 | 財報**未列示**之事項 | 財報中已揭露、查核最關注事項 |
| 性質 | 提醒使用者注意已揭露事項 | 與使用者理解查核/責任攸關 | 本期查核最重要事項之溝通 |
| 是否影響查核意見 | **不影響**（仍無保留）| 不影響 | 不影響 |
| 典型例子 | 重大期後火災、重大不確定訴訟、提前採用新準則 | 前期由其他會計師查核、財報另有目的 | 顯著風險領域、重大判斷/估計 |
| 出無法表示意見時 | — | — | **不得**列 KAM |

> ⚠ **顯著風險 ≠ 當然 KAM**（113-測22 答 D 為「錯誤」敘述）：顯著風險領域只是決定 KAM 的**考量因素之一**，KAM 是查核人員從「與治理單位溝通之事項」中判斷**最為重要**者——**不是「有顯著風險就一定是 KAM」**。
> 另：**決定「未有」須溝通之 KAM 時，仍須列 KAM 段**並敘明「無關鍵查核事項」（不是省略該段，113-測22 B 為正確）。

**口訣**：強調＝「報表有寫，我幫你畫重點」；其他＝「報表沒寫，但你該知道」；KAM＝「我查得最辛苦/最關鍵的」。

**★ 決策流程（拿到情境照走，別再憑感覺選）：**
```
判斷該事項要放哪一段：
① 財報裡「揭露」了嗎？
   ├─ 沒揭露 ───────────────→ 其他事項段
   └─ 有揭露
        └─ ② 是「本期最關鍵、需說明查核如何因應」的嗎？
             ├─ 是 → KAM（要描述為何關鍵＋怎麼查）
             └─ 否，只是要「提醒注意」→ 強調事項段
```
> **兩個高頻陷阱**：①「財報**已適當揭露**」之火災/訴訟/繼續經營不確定性 → **強調事項段**（不是其他事項段）。②**無法表示意見**時 → **不得列 KAM**（除法令另有規定）。
> 差別再收斂：強調/其他**只指出＋索引附註、不描述查核程序**；**KAM 要描述查核程序**。
> 條號：**§10 不得以強調事項段取代個別 KAM 之說明**；**§12 某事項未被決定為 KAM、但依判斷須提醒使用者注意 → 納入強調事項段**（＝上面決策樹的出處）。**無法表示意見仍可含強調/其他事項段**（706 未禁；受限的只有 KAM）。

> ⚠ **更正（先前寫錯，致歉）**：114-測24 官方答案是 **A**——「個體財報查核報告於合併報告日已出具」＝**其他事項段**，那才是「非屬強調事項段」；「呆滯存貨評估之**說明**」在該題反而是**可接受之強調事項段**。
> **關鍵：呆滯存貨評估「可 KAM 亦可強調事項」，看描述**——寫「**關鍵查核判斷/事項**」→KAM；寫「（財報已揭露之）**說明/提醒**」→強調事項段。同一事項，描述方式決定歸類。

## 四、繼續經營（570）四種結果——高頻申論小題

| 情境 | 查核意見 | 段落處理 |
|---|---|---|
| 採繼續經營基礎**不適當**（已不能繼續經營仍用此基礎）| **否定意見** | 基礎段說明 |
| 基礎適當，但**有重大不確定性，且財報已適當揭露** | **無保留** | 加「**與繼續經營有關之重大不確定性**」段（索引至財報附註）|
| 有重大不確定性，但財報**未適當揭露** | 保留／否定 | 基礎段說明揭露不足 |
| 管理階層不願評估繼續經營能力 | 保留／無法表示 | 範圍限制 |

> 110-申1(四) 與 113-測… 反覆考此表，務必精準：**已揭露→無保留＋專段**；不適當→否定。
> **評估時機**：繼續經營能力於**整個查核工作階段**持續評估（非僅規劃或完成階段，112-測25）；評估期間至少為**資產負債表日起 12 個月**（113-測25 型）。存疑時之**額外程序**：要求管理階層評估＋評估因應計畫可行性＋現金流量預測資料可靠性與假設＋期後事實＋書面聲明＋揭露適當性（111-測23）。

## 五、實際考題解題示範

### 範例 1：110-申1（五種獨立情況，每小題 3 分）

| 情況 | 意見類型 | 理由 |
|---|---|---|
| (一) 重大子公司未編入合併報表，影響**重大且廣泛** | **否定意見** | 意見分歧（不實表達）＋廣泛 → 否定 |
| (二) 新系統錯誤影響存貨/成本/應收付等多項，無法以其他程序取證 | **無法表示意見** | 範圍限制＋影響廣泛 → 無法表示 |
| (三) 繼續經營基礎**不適當** | **否定意見** | 採用基礎錯誤 = 重大不實表達 |
| (四) 繼續經營有重大不確定性，**已適當揭露** | **無保留意見** | 加「與繼續經營有關之重大不確定性」段，索引至財報附註 |
| (五) 提醒期後重大火災（財報已揭露）| **無保留意見** | 加「強調事項段」，索引至財報附註 |

**答題要訣**：每小題先寫「意見類型」再寫「理由（原因＋程度）」，繼續經營與強調事項題必須點出「**於何段落、索引至財報附註**」才拿滿分。

### 範例 2：完整申論題型（自編，模擬 115 可能出法）

> 「會計師查核 A 上市公司，發現應收帳款高估且管理階層拒絕更正，金額重大但僅影響應收帳款單一科目。試問應出具何種意見？查核報告哪些段落須修改？是否仍須列報 KAM？」

**解題**：
1. 定性：管理階層拒絕更正 → **意見分歧**。
2. 定程度：金額重大、僅影響應收帳款單一科目 → **重大但不廣泛** → **保留意見**。
3. 須修改段落：**查核意見段**（敘明除保留事項外允當表達）＋**查核意見之基礎段**（具體敘明應收帳款高估金額及對財報影響）。
4. KAM：保留意見仍為上市公司，**仍須列報 KAM**；但**導致保留之事項本身屬修正式意見基礎，於基礎段說明，不在 KAM 段重複溝通**（113-測22 同概念）。

## 五之一、其他資訊（720）與比較財務報表（710）★（112-測15、110-測21）

**其他資訊（720）**＝年報中財報與查核報告**以外**之資訊（如營運概況）。會計師應**閱讀**並考量是否與財報有**重大不一致**：
| 誰要修 | 對方拒絕時 |
|---|---|
| **財務報表**須修正而受查者拒絕 | 影響查核意見 → **否定或保留意見**（112-測15 答 C）|
| **其他資訊**須修正而拒絕 | ⚠改正（§11）：**不影響查核意見，但應於查核報告中「強調」該情事，或採取其他措施（如拒絕出具查核報告／終止委任），必要時徵詢法律專家意見**。台灣 720（＝舊40號）**無查核報告「其他資訊段」，也非「其他事項段」**，別寫錯段名。 |

**比較財務報表（710）**：
- 上期與本期會計政策應**一致**；繼續查核時**得**修改對上期原表示之意見（說「不得修改」＝錯，110-測21）。
- 上期**未經查核** → 於**其他事項段**敘明；上期由**前任**查核 → 其他事項段敘明前任姓名/意見/日期。
- 上期保留原因延續影響本期 → 本期照樣保留/否定。

## 六、本篇必背速記
- 兩原因（意見分歧／範圍限制）× 兩程度（重大不廣泛／重大且廣泛）= 四意見
- 修正式意見必改「查核意見段＋基礎段」
- 強調（已揭露）／其他（未列示）／KAM（最關鍵）三者分清
- 繼續經營：已揭露→無保留＋專段；基礎不適當→否定
- 無法表示意見 → 不得列 KAM；意見段「業經查核」改「受委任查核」
