# 稅務 深掘｜遺產及贈與稅（觀念與規則）★★★

> 補計算範本之外的判斷/規則題。數字見 [10速查表](10_稅務_現行數字速查表.md)，本篇重「課不課、誰課、怎麼判」。
> 計算鏈：**總額 → 不計入 → 扣除額 → 淨額 → 級距稅率 → 應納稅額 → 可抵稅額**。土地稅見 [不動產稅篇](13b_稅務_深掘_不動產稅.md)。

---

## 一、課稅範圍與屬人/屬地 ★★★
| 身分 | 課稅範圍 |
|---|---|
| 經常居住境內之**國民** | 境內＋境外**全部**遺產/贈與財產 |
| 經常居住境外之國民 / 非國民 | **僅境內**之財產 |

**判斷關鍵**＝財產所在地 + 贈與人/被繼承人身分。
- 例：非居住者以境外資金購買**境內**股票贈與 → 境內財產，課稅；以境外資金贈與**境外**再購境內 → 視資金與標的所在判斷（113-申4 四種情境就是考這個排列組合）。

## 二、稅率級距對照（門檻減半記憶法）★★

兩稅門檻擺同一條數線上（套在**課稅淨額**，單位：萬元）：

| 課稅淨額 | 遺產稅 | 贈與稅 |
|---|---|---|
| ≤ 2,811 | 10% | 10% |
| 2,811 ~ 5,621 | 10% | **15%** |
| 5,621 ~ 11,242 | **15%** | **20%** |
| > 11,242 | 20% | 20% |

- **贈與稅門檻＝遺產稅門檻的一半**：2,811 ＝ 5,621÷2、5,621 ＝ 11,242÷2 → 兩稅**共用三個門檻 2,811 / 5,621 / 11,242**，整個遺贈稅只記三個數。
- **贈與永遠「早一格」進高稅率**：贈與每年可重複發生，級距窄、課得快；遺產一生一次，級距寬一倍。
- **累進差額各算各的**：遺產 0／281.05／843.15 萬；贈與 0／140.55／421.6 萬。

## 三、贈與稅 ★★

- **納稅義務人**：**贈與人**（贈與人行蹤不明／逾期未繳且無財產可執行／死亡時尚未核課 → 改受贈人）。
- **視同贈與／以贈與論（§5）** 五情形 ＋ 速記「**兩代一賤，親買監購**」：

| 速記 | 對應 | 但書（舉證可免？）|
|---|---|---|
| **代**償 | 代償／承擔他人債務 | ❌ 無 → 直接課 |
| **代**買 | 自己資金無償為他人購產 | ❌ 無 → 直接課 |
| 一**賤** | 顯著不相當代價讓與（課**差額**）| ❌ 無 → 直接課 |
| **親**買 | 二親等以內親屬間買賣 | ✅ 證明已付價款、款非出賣人提供 → 免 |
| **監**購 | 無／限制行為能力人購產 | ✅ 證明款項屬購買人本人 → 免 |

> 分流：**兩代一賤＝無但書直接課**；**親買、監購＝身分可疑、推定贈與但能舉證推翻**。考點集中在後兩個的舉證免課（尤其二親等買賣的「價款非由出賣人貸與／提供擔保」）。

- **不計入贈與總額（§20）**：配偶相互贈與、扶養義務之生活費教育費醫藥費、公益捐贈、農地農用贈與（受贈人續作農用 5 年）等。

### 贈與稅扣除額／免徵
| 項目 | 內容 | 依據 |
|---|---|---|
| **附有負擔之贈與** | 贈與附負擔，**由受贈人實際負擔**之部分自贈與額**扣除**。要件：①負擔**具財產價值且可確定**②**受贈人真實負擔**（非通謀虛偽、非使第三人受益）。例：贈與設定抵押之房地，未償貸款由受贈人承擔→扣除該債務 | §21 |
| **公共設施保留地** | 限**配偶、直系血親間之贈與**移轉者→**免徵贈與稅**（範圍比遺產稅「因繼承移轉免徵」**窄**）| 都計法 §50-1 |

> **算式**：課稅贈與淨額 ＝ 年度贈與總額 − 免稅額 244萬 − 扣除額（附負擔等）。
> **性質別混**：§20「**不計入**」＝根本不算進來；§21「**附負擔扣除**」＝先算進來再扣；公設保留地＝**免徵**。

## 四、遺產稅 ★★★

- **納稅義務人（三順位）**：①遺囑執行人 → ②繼承人及受遺贈人 → ③依法選定之遺產管理人（有前順位不找後順位）。
- **擬制遺產（§15）**：死亡前 **2 年內**贈與下列之人之財產，併入遺產總額：①被繼承人**配偶**；②依民法 §1138、§1140 之**各順序繼承人**；③前述繼承人之**配偶**。（已納贈與稅及土增稅得扣抵→見五）
- **不計入遺產總額**：被繼承人日常生活必需器具一定金額、公益捐贈、文化古物、捐贈政府等。

### 遺產稅扣除額（六大類記憶架構）
| 類別 | 內容 | 依據 |
|---|---|---|
| **1. 繼承人扣除額** | 配偶 553萬／直系卑親屬 56萬·人（未成年加扣）／父母 138萬·人／重度身障加扣 693萬／受扶養兄弟姊妹·祖父母 56萬·人 | §17 一~五 |
| **2. 特定用途財產** | **農地及地上農作物**：承受人扣**全數**，須**續作農用 5 年**否則追繳；**公共設施保留地**因繼承移轉→**免徵** | §17 六；都計法 §50-1 |
| **3. 短期再轉繼承遞減扣除** | 被繼承人生前**自己繼承／受遺贈且已納遺產稅**之財產，於死亡前 **6/7/8/9 年**內者按 **80/60/40/20%** 遞減扣除（間隔越短減越多，逾 9 年不減）。**基數＝該筆財產價值×遞減%**（非前次遺產總額、非前次稅額）⚠是**扣除額**非稅額扣抵；冷門低頻 | §17 七 |
| **4. 被繼承人負債（含對政府）** | 死亡前**未償債務**（須確證）／死亡前依法**應納未納之稅捐、罰鍰、罰金** | §17 八、九 |
| **5. 必要費用** | **喪葬費 138萬（定額**，不論實支）／**執行遺囑及管理遺產**之直接必要費用 | §17 十、十一 |
| **6. 配偶剩餘財產差額分配** | 婚後財產差額之**半數**，自遺產總額扣除（詳見下）| §17-1／民 1030-1 |

> **扣除額 ≠ 稅額扣抵**：上表都是從**遺產總額**減（減稅基）；稅額扣抵（從應納稅額減）見「五」。

### 繼承順序 × 扣除額（先定繼承人，才知道減哪些）
民法 §1138：繼承人（**配偶除外**）依序定之，**前順序排除後順序**：

| 順序 | 繼承人 | 對應扣除額 |
|---|---|---|
| **第一** | 直系血親卑親屬（子女；先死則孫輩**代位繼承** §1140）| 每人 **56萬**（未成年加扣）|
| **第二** | 父母 | 每人 **138萬** |
| 第三 | 兄弟姊妹 | 受扶養每人 56萬 |
| 第四 | 祖父母 | 受扶養每人 56萬 |

**配偶（§1144）一定有繼承權**，不排順序，與當時順序人共同繼承，應繼分隨對象變：

| 配偶與誰共同繼承 | 配偶應繼分 |
|---|---|
| 第一順序（卑親屬）| 與卑親屬**按人數均分** |
| 第二／第三順序（父母／兄弟姊妹）| 配偶 **1/2**，餘 1/2 均分 |
| 第四順序（祖父母）| 配偶 **2/3**，餘 1/3 均分 |
| 無任何順序繼承人 | 配偶**全部** |

- **計算題關鍵**：扣除額按**實際繼承人**算。有子女（第一順序）→ 父母非繼承人、**不得**減 138萬；能減配偶 553萬＋每名子女 56萬。配偶扣除額 553萬與「應繼分」無關，只要配偶在就減。
- **未成年加扣（民法 18 歲成年連動，必考）**：卑親屬／受扶養兄弟姊妹中**未滿 18 歲**者，按距 18 歲年數每年加扣 56萬；**18 歲已成年→無加扣**。
- **拋棄繼承**者**不列其扣除額**；其應繼分由其他繼承人／代位者承受。

### 剩餘財產差額分配請求權（§17-1／民 1030-1）★★
- 法定財產制關係消滅（含一方死亡）時，**婚後財產較少**之一方得請求差額**半數**。
- 生存配偶主張時，該金額**自遺產總額扣除**（須於核課時主張並於一定期間給付）。

## 五、可抵稅額（稅額扣抵）★★

**扣抵 ≠ 扣除**：扣除額從**總額**減（減稅基）；可抵稅額從**應納稅額**減（減稅金）。

| 稅目 | 可抵稅額 | 依據／重點 |
|---|---|---|
| **遺產稅** | **擬制遺產**（死前 2 年贈與、依 §15 併入）已納之**贈與稅＋土地增值稅＋利息**，自應納遺產稅額扣抵 | §11Ⅱ。**扣抵上限＝該贈與財產併入後增加之應納遺產稅額** |
| **贈與稅** | 同一年度 **2 次以上**贈與 → **合併累計**算稅後，**減除前次已繳之贈與稅額**＝當次應納 | §19。年度累計課徵，避免同年重複 |

## 六、實物抵繳 ★★
- 要件：應納稅額 **30 萬以上**、納稅義務人確有困難不能一次繳現、於繳納期限內申請。
- 抵繳標的＝課徵標的物或易於變價/保管之實物。
- **抵繳限額**：以該標的物**佔全部課徵標的物價值比例 × 應納稅額**為限。
- **公共設施保留地**抵繳：以該地**公告現值**為抵繳價值（非屬遺產者另有比例限制）。
- 上市股票抵繳：以**繳納時**收盤價計（股價跌時抵繳價值隨之降低，113-測25）。

## 必背速記
- 屬人屬地：境內國民全部財產、境外/非國民僅境內財產
- 級距三門檻 2,811／5,621／11,242（贈與＝遺產的一半）
- 以贈與論 §5「兩代一賤親買監購」；擬制遺產 §15 死前 2 年贈與配偶/繼承人
- 遺產稅扣除額六大類；拋棄繼承不列扣除；剩餘財產差額分配半數可扣
- 可抵稅額：遺產（擬制遺產已納贈與稅+土增稅+利息，有上限）／贈與（年度累計減前次已納）
- 實物抵繳：30 萬以上、按比例限額、公設地公告現值、股票繳納時收盤價
- 18 歲成年連動未成年加扣
