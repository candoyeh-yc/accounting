## 弱點題型總表（出題加強清單）

| 題型 | 弱點 | 出題加強方向 |
|---|---|---|
| 營業稅—兼營比例扣抵 | 零稅率有沒有算進「得扣抵」分子；應納 vs 退稅方向 | 每份必出 1 題，含零稅率＋固定資產 |
| 遺產稅—扣除額 | 免稅額／扣除額／扣抵稅額三者混淆 | 出題故意把三者並列誘答，只問其中一項 |
| 遺贈稅—贈與稅計算 | ①漏扣年度免稅額 ②**不動產贈與漏扣土增稅／契稅（施行細則§19得自贈與總額扣除）** ③**代繳土增稅＝先加(65函釋視同贈與)後扣(§19)互抵** ④**級距依年度選**：114年度起2,811/5,621萬；113年度及以前2,500/5,000萬 | 必出不動產或股票贈與計算，要求列「贈與總額(±代繳視同贈與) → 扣土增稅/契稅 → 減免稅額 → 淨額 → 級距」全流程 |
| 遺產稅—擬制遺產 | 死亡前 2 年贈與是否併入；小題是否承接事實容易混淆 | 題目必明示「各小題獨立」或「承上題」；若承接，刻意考已課贈與稅之擬制遺產與扣抵 |
| 房地合一 | ①版本判斷（出售日決定 1.0/2.0）、不敢動筆 ②稅率級距背錯（誤用 25%）③土增稅誤加回所得稅 | 必出計算題，出售日設近年（2.0）；題目給土地漲價總數額誘導「加回土增稅」；偶爾考 1.0 vs 2.0 差異觀念題 |
| 地價稅—累進 | 倍數對但套錯級距稅率 | 出題讓倍數落在 5–10 倍（25‰）或更高，逼用速算公式 |
| 營利事業基本稅額 | 基本所得額加計項目、60 萬扣除額與補繳差額順序混淆 | 出題改用不同免稅所得組合，要求列「基本所得額 → 扣除 60 萬 → 基本稅額 → 與一般稅額比較」 |
| 土地增值稅—一般級距 | 自用住宅 10% 穩定，但一般用地累進級距易直接用 20% | 出題給漲價倍數剛好 100%、200% 或超過 200%，要求分段法與速算法驗算 |
| 土地稅—地價稅基準日 | 地價稅納稅義務人基準日 8/31 誤記為年底 | 測驗題用房屋稅/地價稅/申報稅目混合考，避免只靠直覺猜日期 |
| 核課期間 / 程序 | 已申報無故意＝5 年 vs 7 年混淆 | 程序題每份夾 1–2 題 |
| 稅捐稽徵—滯納金 | 每逾 3 日加徵 1%、最高 10% 易混成「每逾 10 日」 | 測驗題拆問「加徵週期」與「最高上限」，避免只背到 10% |
| 跨境電商 / 門檻數字 | 稅籍登記 48 萬等門檻記不牢 | 數字門檻題輪流出 |
| 營業稅—留抵/溢付退稅 | 退稅限額公式會混成「溢付額按零稅率比例」；上期留抵容易漏進本期淨額 | 下回再考一次零稅率銷售額×5%＋固定資產進項，並要求先算本期溢付總額 |
| 所得稅—計算手滑 | 房地合一所得、稅率乘法等基本算術連續出錯 | 計算題維持多小題承接；每題要求寫完後反查減法/乘法 |

| 土地稅—公設保留地 | 未使用且隔離＝免徵，常誤選累進 | 列為易錯測驗題 |
